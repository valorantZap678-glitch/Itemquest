# ItemQuest Free Web App

This is a mobile-first static web app. It uses localStorage, so the collection and deck stay on the device/browser.

## Free hosting
GitHub Pages can host static HTML/CSS/JavaScript from a public repository on GitHub Free.

## Current features
- Home screen
- Camera/photo upload
- Local card generator
- Collection
- 20-card deck
- Pass-and-play battle
- Installable PWA manifest

## Important
The current free card generator does not claim to identify objects with AI. It uses the selected file name and randomized original stats/types. A real AI vision service can be connected later, but that requires an external API/service.

Do not put an API secret in this static website.

## Publish
Create a public GitHub repository, upload index.html, manifest.webmanifest, and icon.svg, then enable GitHub Pages for the repository.
